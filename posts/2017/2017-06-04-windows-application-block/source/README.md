# Windows Application Block source snapshot

This directory contains the source code that accompanies the [Windows Application Block article](../index.md).

The snapshot was imported from the original [`oleksandr-bilyk/WindowsApplicationBlock`](https://github.com/oleksandr-bilyk/WindowsApplicationBlock) repository at commit `d3cf1d910e3ce9b020e5ac1dfadbd5579783d09f`, originally pushed on June 4, 2017.

The original `docs/README.md` became the article, and `docs/images` became the article's adjacent `images` directory. The remaining repository files are preserved in this source directory.

The solution was created for Visual Studio 2017-era Universal Windows Platform development. Its UWP projects target Windows 10 SDK version `10.0.15063.0`, and its application-logic projects target .NET Standard 1.1. The code is preserved as a historical sample and is not presented as a currently supported UWP application template.
